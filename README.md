# Генеративные нейросети

Минимальный проект для лабораторной работы по генерации текста.

Реализованы:

1. Simple RNN с посимвольной токенизацией.
1. Simple RNN с токенизацией по словам.
1. Однослойная и многослойная LSTM с посимвольной токенизацией.
1. Однослойная и многослойная LSTM с токенизацией по словам.
1. Однослойная и многослойная LSTM с BPE-токенизацией.
1. Двунаправленная LSTM.

## Запуск

```bash
pip install -r requirements.txt
python train_models.py
```

Результаты сохраняются в `outputs/results.json`.
Отчет находится в `Report.md`.
Ноутбук находится в `notebooks/lab2_text_generation.ipynb`.
