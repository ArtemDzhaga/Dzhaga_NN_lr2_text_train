# Генеративные нейросети

## Задание

Цель работы: натренировать и сравнить несколько простых генеративных моделей для текста.

В базовом варианте проекта реализованы:

1. Simple RNN с посимвольной токенизацией.
1. Simple RNN с токенизацией по словам.
1. Однослойная LSTM с посимвольной токенизацией.
1. Многослойная LSTM с посимвольной токенизацией.
1. Однослойная LSTM с токенизацией по словам.
1. Многослойная LSTM с токенизацией по словам.
1. Однослойная LSTM с токенизацией на основе BPE.
1. Многослойная LSTM с токенизацией на основе BPE.
1. Двунаправленная LSTM с посимвольной токенизацией.

Трансформерная архитектура и дообучение GPT не выполнялись, потому что в работе сделан только базовый минимум.

## Датасет

Используется небольшой текстовый датасет `data/sample_text.txt`.
В него включен стих АС Пушкина. Такой датасет маленький, поэтому модели обучаются быстро и подходят для демонстрации процесса.

В реальной работе качество будет выше, если заменить этот файл на большой текстовый корпус, например русскую литературу с lib.ru или английскую литературу с Project Gutenberg, как писалось в задании лабы.

## Подготовка текста

Текст приводится к нижнему регистру. Лишние переносы строк заменяются пробелами.

Использованы три способа токенизации:

1. Посимвольная токенизация: каждый символ является отдельным токеном.
1. Токенизация по словам: каждое слово является отдельным токеном.
1. BPE-токенизация: частые пары соседних токенов постепенно объединяются в более крупные части слов.

Для обучения строится задача предсказания следующего токена по предыдущим токенам.

## Архитектуры

Simple RNN является самой простой рекуррентной моделью. Она быстро обучается, но плохо запоминает длинный контекст.

LSTM лучше работает с последовательностями, потому что использует специальные ворота для хранения и забывания информации.

Многослойная LSTM содержит две LSTM-слоя. Такая модель может находить более сложные зависимости, но обучается дольше.

Двунаправленная LSTM читает последовательность в двух направлениях. В задании просили однонаправленную, но всё равно добавил эту архитектуру для сравнения.

## Запуск

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск обучения:

```bash
python train_models.py
```

После запуска создается папка `outputs`.
В ней сохраняется файл `outputs/results.json` с метриками и примерами генерации.

## Ожидаемые результаты

Так как датасет маленький и обучение короткое, качество генерации будет учебным.
Модели обычно начинают повторять отдельные символы, слова и похожие фрагменты текста, но не строят полностью связный литературный текст.

Ожидаемое сравнение:

| Модель | Токенизация | Ожидаемое качество |
|---|---|---|
| Simple RNN | символы | низкое, но видна структура букв |
| Simple RNN | слова | низкое, часто появляются случайные слова |
| LSTM 1 слой | символы | лучше Simple RNN, текст похож на исходный |
| LSTM 2 слоя | символы | немного лучше, но требует больше данных |
| LSTM 1 слой | слова | может запоминать отдельные словосочетания |
| LSTM 2 слоя | слова | лучше на большом датасете, на маленьком может переобучаться |
| LSTM 1 слой | BPE | баланс между символами и словами |
| LSTM 2 слоя | BPE | лучший вариант среди базовых при достаточном датасете |
| Bidirectional LSTM | символы | полезна для сравнения, но не очень для пошаговой генерации |

## Вывод

В работе реализован минимальный набор генеративных текстовых моделей.
Simple RNN подходит как базовая модель для сравнения.
LSTM обычно дает более качественную генерацию, потому что лучше учитывает контекст.
BPE-токенизация удобна тем, что уменьшает проблему редких слов и сохраняет части слов.

Для улучшения результата нужно увеличить датасет, число эпох и размер моделей.
